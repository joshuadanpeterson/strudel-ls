# Changelog

All notable changes to this project will be documented in this file by Release Please.

## [0.1.0] - Initial prerelease
- Bootstrap LSP skeleton with core features

### Added
- Context-aware completions (sounds inside `s("…")`, transforms with snippets)
- Hover with signature/blurb/example
- Signature help from builtin signatures
- Diagnostics for unknown transforms with quick-fix; basic string error check
- Formatting normalization for pipes/commas and optional wrapping
- Workspace discovery for `.str` and `.strdl`
