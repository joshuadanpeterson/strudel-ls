# Strudel Language Server (strudel-ls)

This repository contains the Strudel LSP implementation.

- Primary package: `packages/strudel-ls`
- Parser requirement: uses the tree-sitter Strudel grammar from https://github.com/PedroZappa/tree-sitter-strdl (npm dep `tree-sitter-strdl`). Ensure native build tools are available.
- Neovim examples and Mason/lspconfig snippets are included under the package and misc folders.

See `packages/strudel-ls/README.md` for installation and usage details.
